# Theory notes

One note per concept, written at the moment the concept is first needed and before the
code that uses it. Each note derives or motivates its formulas rather than asserting
them — if a result appears here without a derivation or a clear argument for why it
holds, that is a defect in the note.

These notes are a deliverable, not scratch work. They are the material for explaining
this project to someone else, and they feed the README directly.

They are distinct from `LEARNING_LOG.md`, which records the *experience* of each
session — what was taught, what landed, what did not. These notes record the
*mathematics*.
